# 🧩 MazeUp

A sleek, modern, and responsive interactive maze puzzle game built completely using vanilla **HTML5**, **CSS3**, and **JavaScript**. Enjoy randomized mazes, multiple difficulty levels, a built-in timer, move counter, local best score tracking, sound effects via the Web Audio API, and an optional **Fog-of-War** mode!

---

## ✨ Features

- **Procedural Maze Generation:** Every new game generates a unique, solvable maze using Depth-First Search (DFS).
- **Multiple Difficulties:** 
  - **Easy:** 15x15 grid
  - **Medium:** 25x25 grid
  - **Hard:** 35x35 grid
- **Fog of War Mode:** Toggle on for an extra challenge where visibility is limited around the player.
- **Stats & Local Storage:** Tracks your moves, elapsed time, and saves your best scores per difficulty using browser LocalStorage.
- **Audio Feedback:** Immersive sound effects powered by the native browser Web Audio API (no external audio files needed).
- **Responsive & Lightweight:** Zero external dependencies or frameworks—just open and play instantly!

---

## 🎮 How to Play

1. Open `index.html` (or `mazeup.html`) in any modern web browser.
2. Use your keyboard arrow keys or **W, A, S, D** to navigate the blue glowing orb through the corridors.
3. Reach the green exit square at the end of the maze as fast as possible with the fewest moves!
